Last updated: August 2026

This website is a static site. I do not use advertising cookies, social-media pixels or Google Analytics.

## Cookies set by this website

The pages themselves do not set cookies. There is no login, no contact form and no cookie banner, because there is nothing here that needs your consent to store a cookie.

## Cloudflare

The site is hosted on Cloudflare Pages. With the usual cookie-light settings (no Bot Fight Mode, no email obfuscation, no Rocket Loader), Cloudflare does not need to set cookies for the site to work.

If extra Cloudflare security features were turned on later, Cloudflare might set strictly necessary cookies such as `__cf_bm` or `cf_clearance` to tell automated traffic from people. Those would be used only for security, not for marketing. I would update this page if that changed.

## Links to other sites

If you open an article or register page on another website, that site may set its own cookies. That is outside this policy.

If you have questions about cookies or this website, email [ewcounselling@tutanota.com](mailto:ewcounselling@tutanota.com).
